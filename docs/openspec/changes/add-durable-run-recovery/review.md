## 已收敛的问题

| 检查点 | 结论 |
|---|---|
| 文档声称已有 RunTask | 按源码和 V21 校准为“表存在，当前模型/调度/API 未接通”，不得在其上假定现成执行器 |
| ID 与历史记录 | 已用 PostgreSQL 证明同范围执行项会转移归属；S1 先解决独立身份及历史隔离 |
| 数据库事务覆盖 Git | 明确外部效果不能被数据库回滚；使用先持久化意图、短事务与核对 |
| 租约等于 exactly-once | 已否定；过期 worker 数据库 CAS 不代表外部请求被阻止；未知请求保留写入阻断 |
| 查不到就可以重试 | 已禁止；请求在途、分页、权限或读取失败均不能作为“未执行”证明 |
| retry 会改写历史终态 | 已收敛为新 Run 与新 attempt；resume 仅用于未终结的恢复状态 |
| 关闭窗口语义 | 明确采用当前已验收“关闭触发收尾”，并用 delta spec 修订旧描述；由提案评审确认 |
| 旧入口与新调度并行 | S2 必须覆盖所有写入口；未纳入者在启用范围内显式阻断，不能仅检查后继续写 |
| GitLab 文档版本差异 | 当前官方文档只作设计依据，17.11.3 能力要在 S2 实测，不挪用 19.x 特性 |
| 当前测试含义 | 6 项新测试证明旧缺口仍存在，不代表恢复实现；未来切片必须替换为目标断言 |
